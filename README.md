## 

## Sobre o projeto:

- Repositório criado para a elaboração do MVP FrontEnd do curso de Análise e desenvolvimento de sistemas (ADS).
- Para acessar o site: 🔗 [Link para o site](https://mateusty.github.io/MVP-FrontEnd)

## Dores do público:

- **Informações espalhadas**: As informações sobre os parques está espalhada em diversos sites;
- **Dificuldade de agendamento**: Com as informações dispersas, complica-se o agendamento de eventos nos parques.

## Objetivos:

- **Unificar a pesquisa de informações**: Juntar as informações sobre os parques em um só lugar;
- **Facilitar a consulta de eventos**: Deve ser possível adicionar e consultar eventos nas localidades.
